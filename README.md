# Bizzapt — Collage Hero Prototype

This is a small static prototype for the Bizzapt hero section featuring a creative collage of 6 interactive cards with a logo mask overlay.

Quick start

1. Open the folder in a static dev server or VS Code Live Server.

2. Open `index.html` in your browser.

Replace the logo

- Put a high-quality SVG or PNG with transparency at `assets/logo.svg`. The mask uses that file to cut a logo-shaped window over the collage. Replace the placeholder SVG with your supplied high-res logo for best results.

Notes

- Cards rotate/flip on click and reveal short descriptions. Keyboard: press Enter or Space while focused on a card.
- Tweak sizes in `styles.css` variables to fit your visual preferences.
